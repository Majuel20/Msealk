# Datos publicados para MSealk

La app descarga `cortes_programados.json` desde la rama `main` de `Majuel20/MSealk`.

Se incluyen JSON, CSV, TXT y Excel de la última extracción local validada. La fecha de extracción figura en `metadata.fecha_ejecucion`; estos archivos no garantizan que la fuente esté disponible en este momento. Cada ejecución correcta del actualizador los reemplaza.

La estructura JSON contiene `metadata`, `total` y `cortes`. No cambies la ubicación del JSON sin actualizar también la URL en Android.
